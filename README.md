# MultiStream

Android-застосунок (Kotlin, Jetpack Compose, Media3/ExoPlayer): перегляд кількох стрімів в одному вікні.

## Можливості
- Сітка плиток, що заповнює екран (1–9 стрімів), розкладка залежить від орієнтації.
- Тап по плитці — розгортання на весь екран (звук увімкнено, показано елементи керування).
- Кнопка ✕ або «Назад» — повернення до сітки.
- Довгий тап по плитці — меню: розгорнути / перезапустити / видалити.
- У сітці всі стріми без звуку; у повноекранному режимі решта ставиться на паузу (економія трафіку).
- Список стрімів зберігається між запусками.
- Підтримка HLS, DASH, RTSP, прогресивного MP4.

## Збірка
1. Відкрити папку `MultiStream` в Android Studio (Koala або новіша, JDK 17).
2. Дочекатись Gradle Sync (Studio сама завантажить Gradle 8.9 за `gradle-wrapper.properties`).
3. Run ▶ на пристрої або емуляторі (minSdk 24).

## Обмеження
- Посилання YouTube/Twitch напряму не відтворюються: потрібен прямий URL потоку.
- RTMP не підтримується без окремого розширення Media3.
- Кількість одночасних декодерів залежить від телефону; на слабких пристроях 4–6 потоків — реальна межа.
